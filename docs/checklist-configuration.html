Tout ce que vous devez faire et configurer

Le développement se fait entièrement en cloud/git : le code est écrit, testé et poussé sur GitHub sans aucune machine locale. Ce qui relève vraiment de vous se limite à trois choses : Hostinger (étape 3), les secrets (étape 4) et vos exports DEGIRO (étape 2). L'étape 1 (poste local) est facultative — seulement si un jour vous voulez faire tourner l'app sur votre propre machine. Vos cases cochées sont mémorisées dans ce navigateur.

Règles non négociables

  • Jamais d'identifiants DEGIRO côté serveur ni dans l'extension — la capture se fait dans votre session navigateur déjà authentifiée.
  • Jamais de .env, de token ni de données financières réelles commitées dans Git.
  • Jamais la base de production comme base de développement.
  • Jamais « Any Host » sur Remote MySQL — restreindre à votre IP.
